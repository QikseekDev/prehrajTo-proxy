Vypnuto (výchozí): náhledy na úvodní stránce se načítají. Zapnuto: žádné dotazy ani obrázky, jen barevné placeholdery.
iTunes Search API: oficiální plakáty filmů, bez API klíče; když film nenajde, použije se prehraj.to.
Odkud se na úvodní stránce berou filmy: výchozí žebříček iTunes CZ, nebo anglický iTunes US. Seznam včetně plakátů stáhne server a cacheuje na 1 den - bez klíče a bez účtu.
Vypnuto (výchozí): náhledy se načítají všechny naráz. Zapni, pokud prehraj.to vrací chybu 429.
Zapnuto (výchozí): dotaz jde souběžně na všechny zaškrtnuté servery níže, použije se první úspěšná odpověď (chyba/výpadek jednoho serveru appku nezastaví). Vypni úplně, aby appka volala prehraj.to přímo z Azure.
