Cache

Server drží výsledky hledání (30 min), náhledy (7 dní) a katalog (1 den). Špatný plakát nebo zastaralý výsledek jinak počká, až vyprší TTL.

Bany

Dočasné zablokování IP nebo klienta (cid z localStorage) mimo rate limit. Použij, když někdo scrapuje – limit 6/s ho jen zpomalí.

Nejaktivnější klienti

Počty od startu procesu; po restartu se vynulují.

Audit
